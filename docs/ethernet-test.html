🧪 Wallbox Gateway — Ethernet (W5500) Test

Experimental wired-Ethernet build. No WiFi — pulls DHCP over the RJ45, freeing the ESP32's radio for BLE.

⚠️ Experimental & untested on hardware. This is a first-flash trial build for community testers. Pins are set for the base Waveshare ESP32-S3-ETH (the Type-C + microSD board). Other variants (POE-ETH, 8DI-8RO) wire the W5500 to different GPIOs and won't work with this build.

One-click install

⚠️ Your browser doesn't support Web Serial — use desktop Chrome or Edge. ⚠️ This page must be served over HTTPS to flash.

Full erase + flash of the Ethernet build. ESP32-S3 boards only. Takes about a minute.

Needs desktop Chrome or Edge (Web Serial). Or via CLI:
esptool.py --chip esp32s3 write_flash 0x0 wallbox-eth-test.bin

After flashing

  1. Open a serial monitor at 115200 and watch for: 
    [ETH] W5500 up (...)
[ETH] DHCP lease 192.168.x.x
  2. Browse to that IP → the gateway web UI → set your charger's BLE + your MQTT broker (no captive-portal step on the wired build).
  3. Confirm BLE connects and stays stable to the Pulsar.

No [ETH] line? The pins are likely off for your exact board — report back in the community thread and it's a quick fix.
